# 标注演示 · 静态化改造说明

本目录是读写评估系统的前端标注界面静态演示版。页面不依赖 Flask、数据库或登录状态，打开后会加载两名虚构学生的样例数据；所有标注、截图新增、截图删除和导出操作都在浏览器内完成。

## 一、文件清单

| 文件 | 作用 |
| --- | --- |
| `index.html` | 量表标注页（由原服务端模板静态化而来） |
| `css/marking.css` | 原样式文件，原样复制，未做视觉改动 |
| `js/marking.js` | 量表标注逻辑；已移除登录跳转与真实接口地址，图片和接口统一走演示层 |
| `js/mock-data.js` | 两名虚构学生的完整表单数据、答题页图片、脱敏截图路径 |
| `js/mock-api.js` | 浏览器本地 mock：接管请求、读写 localStorage、导出 JSON、解析图片地址 |
| `images/icon.png` | 页面图标，路径改为相对路径 |

源模板、源脚本和样例截图目录均只读使用，未修改。截图素材仍位于本目录同级的 `screenshots` 文件夹内。

## 二、打开与部署

推荐通过静态服务器或线上静态站点访问，例如访问：

```text
02-报告自动化/标注演示/index.html
```

发布时必须保留以下相对结构：

```text
02-报告自动化/
├── 标注演示/
│   ├── index.html
│   ├── css/
│   ├── js/
│   └── images/
└── screenshots/        ← 脱敏样例截图
```

页面中的种子截图使用 `../screenshots` 相对路径，不要只单独拷贝 `标注演示` 目录，否则答题页图片和截图缩略图会失效。

页面也验证过可以直接以本地文件方式加载图片和数据，但直接双击 HTML 时，浏览器会禁止导出画布内容，导致“框选错题截图”不可用。请通过静态服务器或线上地址使用完整功能。

## 三、演示模式如何工作

### 1. 加载顺序

两个页面都在页面脚本之前加载：

```text
js/mock-data.js → js/mock-api.js → js/marking.js / 识字量内联脚本
```

`js/mock-data.js` 只提供数据；`js/mock-api.js` 在最外层替换 `window.fetch`，并根据请求路径、请求方法返回一个本地 `Response` 对象。页面原有的 `fetch(...)` 与 `response.json()` 写法保持不变，因此不需要重写页面业务代码。

### 2. 请求路由

接口路径常量只保留在 `js/mock-api.js` 内，页面脚本通过 `window.SCALEMARK_DEMO.endpoint(...)` 获取演示路由。所有请求都在浏览器内被截获，不会发送到服务器。

| 页面调用的接口名 | 本地行为 |
| --- | --- |
| `students` | 返回001、004两名虚构学生 |
| `student_data` | 返回对应学生的答题页图片数组和完整记录 |
| `screenshots` | 返回该学生的截图分组（同一文件名跨分类合并） |
| `save` | 合并表单字段、重算总分，并写入 localStorage |
| `save_screenshot` | 压缩现场框选图，生成浏览器内截图记录并写入 localStorage |
| `delete_screenshot` | 删除新增截图，或隐藏种子截图 |
| `download_all_screenshots` | 返回浏览器内生成的截图清单 JSON |
| `export_excel` | 返回浏览器内生成的成绩记录 JSON |

没有列入上表的接口不会透传，统一返回“演示模式暂未提供该接口”的本地错误响应。

### 3. 本地存储

localStorage 键名为：

```text
scalemark_static_demo_v1
```

主要结构：

```js
{
  version: 1,
  records: {
    "<学生目录>": { /* 完整学生记录，包含 low_data / high_data */ }
  },
  screenshots: {
    "<学生目录>": {
      added: [ /* 现场新增的截图；图片为压缩后的 data URL */ ],
      hidden: [ /* 被删除的种子截图 capture_id */ ],
      hiddenPaths: [ /* 被删除的种子截图路径 */ ]
    }
  }
}
```

保存后刷新页面，标注结果和新增截图仍会回显；清除站点数据或换一个浏览器/设备后会回到预置样例。页面左上角的学生序号也会写入原有的 `last_student_index`，两个页面共享。

### 4. 图片路径规则

`window.SCALEMARK_DEMO.imageUrl()` 统一处理三类图片：

- 种子截图：`学生目录/分类/文件名.png` → `../screenshots/学生目录/分类/文件名.png`，逐段编码中文和括号；
- 现场新增截图：使用 Canvas 压缩后的 JPEG data URL，直接可显示；
- 已是 data/blob/http(s) 地址的图片：原样返回。

种子数据中返回的 `images`、`previewPath` 和 `categories[].path` 都对应真实存在的文件；现场新增截图只存在于当前浏览器，这是纯静态演示的边界。

### 5. 演示数据

| 学生 | 年级 | 量表原始总分（满分 42） | 百分制总分 | 识字量结果 | 截图分组 |
| --- | --- | ---: | ---: | ---: | ---: |
| 001 | 二年级 | 34.0 | 81.0 | 27 / 36 | 9 组（18 个文件） |
| 004 | 三年级 | 37.5 | 89.3 | 35 / 45 | 22 组（75 个文件） |

- 姓名、学校、日期、分数均为虚构或演示换算值，不代表真实测评结论。
- 量表总分按原系统的字段口径和满分 42 分重算；未展示的百分制总分也一并写入导出记录。
- 记录中同时包含量表字段与识字量逐字状态，因此同一个学生可在两个页面之间切换。
- 左侧“答题页”使用已脱敏错题截图拼成 3 至 4 页演示素材，不包含真实儿童身份信息。

## 四、按钮与功能状态

### 真实可用的交互

- 学生搜索、上一份/下一份、序号跳转；
- 量表页低年级/高年级随年级自动切换；
- 所有单选、数字输入、统计框、“+ / -”按钮；
- 最终得分自动重算（保存后回显）；
- 答题页翻页、滚轮缩放、鼠标框选错题；
- 截图上传弹窗：填写正确汉字、勾选一项或多项错误分类后保存；
- 截图管理：筛选、缩略图、放大预览、删除截图；
- 识字量页逐字“正确 / 无法识读 / 错误”、批量区间状态、撤销、保存；
- 两个页面的保存、学生切换、快捷键（方向键翻页，Shift + 上下键切换学生，Ctrl/Cmd + Enter 保存）；
- 刷新后从 localStorage 恢复已保存的数据；
- 两个导出按钮均在浏览器内生成文件，不请求服务器。

### 降级或演示边界

- “导出 Excel”仍保留原按钮文案，但在演示模式下下载的是 `.json` 数据文件，不是 `.xlsx`。
- “下载全部截图”下载的是截图清单 JSON，不是 `.zip` 图片压缩包；现场新增截图以 data URL 形式包含在清单中。
- 没有真实后端、云端同步、账号登录和跨设备共享；清除浏览器数据即恢复初始状态。
- 现场框选的新截图不会落盘为独立图片文件，只保存在本机浏览器。
- 量表页“返回上页”调用浏览器历史；从作品集入口进入时可正常返回，直接打开单页时可能没有可返回的历史。
- 识字量页“返回首页”指向量表标注首页 `index.html`。
- 导出只包含当前浏览器中已保存的数据；未保存的表单修改不会进入导出文件。
- 浏览器 localStorage 空间不足时，保存截图会提示失败，不会上传到任何服务器。

## 五、验收自查

1. **语法**
   - `node --check js/mock-data.js` 通过；
   - `node --check js/mock-api.js` 通过；
   - `node --check js/marking.js` 通过；
   - 两个 HTML 中的内联脚本提取后 `node --check` 通过。

2. **资源路径**
   - 两名学生的 93 个种子截图文件与 7 条答题页引用（去重后）共 100 条路径全部存在；
   - 页面引用的 CSS、图标、三个脚本路径均存在；
   - mock 返回的种子 `previewPath` 和分类路径均为真实文件；新增截图使用可显示的 data URL。

3. **残留检查**
   - 页面和业务脚本中不存在服务端模板语法、模板 URL 函数、登录跳转或真实后端接口地址；
   - 接口路径常量仅出现在 `js/mock-api.js`；
   - 目录中不含原始真实儿童姓名或原实验室标识。

4. **浏览器交互**
   - 使用无头 Chrome 在本地静态服务器上完成：首页加载、两名学生切换、低/高年级表单回显、保存后刷新回显、实际鼠标框选上传截图、截图列表刷新、删除新增/种子截图、两个导出接口、识字量低/高年级列表与保存；
   - 两个页面均无控制台异常；
   - 桌面截图与线上入口路径格式一致，答题页图片和缩略图均成功加载。

## 六、维护提示

- 新增样例学生：在 `js/mock-data.js` 中补充学生记录、答题页图片和截图路径，路径仍使用相对 `screenshots` 的目录格式。
- 调整种子截图：保持“学生目录/分类/文件名”的结构，文件名末尾保留 13 位时间戳时，截图列表会显示对应创建时间。
- 修改后请重新执行语法检查、路径存在性检查和一次浏览器交互回归。
- localStorage 数据与数据结构版本绑定；若修改了 `version` 或字段结构，建议同时更换存储键名，避免旧缓存干扰。
